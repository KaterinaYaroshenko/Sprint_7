# Автоматизация тестирования API Яндекс.Самокат

Проект содержит автотесты для учебного сервиса **Яндекс.Самокат**. Тестирование охватывает функциональность создания курьеров, авторизации и работы с заказами.

## 🛠 Технологии и инструменты


| Технология | Версия | Описание |
| :--- | :--- | :--- |
| **Java** | 11 | Язык программирования |
| **JUnit** | 4.13.2 | Фреймворк для написания тестов |
| **Maven** | 3.9.0 | Сборщик проекта |
| **RestAssured** | 5.3.0 | Библиотека для тестирования API |
| **Lombok** | 1.18.30 | Аннотации для сокращения шаблонного кода (POJO) |
| **Allure** | 2.21.0 | Генерация отчетов о тестировании |

## Структура проекта

*   `src/main/java/client` — клиентские классы для отправки запросов (CourierClient, OrderClient).
*   `src/main/java/model` — POJO-модели данных (Courier, Order, Credentials).
*   `src/test/java` — тестовые классы и базовый класс `BaseTest` с общей конфигурацией.

## Настройка и запуск

### Предварительные условия:
1. Установлен **JDK 11** или выше.
2. Установлен **Maven**.
3. В IntelliJ IDEA включена настройка **"Enable annotation processing"** (для работы Lombok).

### Запуск тестов:
Для запуска всех тестов выполните команду в терминале:
`mvn clean test`

### Генерация Allure отчета:
После прохождения тестов выполните команду:
`mvn allure:serve`

## Основные проверки
- **Курьер**: создание (позитивные и негативные кейсы), логин, удаление после тестов.
- **Заказы**: создание с различными комбинациями цветов (параметризованные тесты), получение списка заказов.
- **Очистка данных**: автоматическое удаление созданных сущностей в методах `@After`.
